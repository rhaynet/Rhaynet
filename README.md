# Faruk Abioye

**Software Engineer | Mobile, Backend and Applied AI**

I'm a software engineer based in Derby, UK. I build mobile products with Flutter and Dart, and I work across the backend services, cloud infrastructure, testing and release pipelines needed to put them in people's hands.

Recent work has taken me through FastAPI and PostgreSQL systems, Firebase and AWS services, real-time WebSockets, React and TypeScript websites, and on-device computer vision. I like owning a product from the first architecture decisions through store delivery.

## Selected work

- **ICallOn**: A multiplayer Name-Place-Animal game that I developed as the sole engineer. It supports Firebase rooms for up to eight players, synchronised rounds, reconnect and rejoin flows, bot backfill and peer judging. I also built a human-in-the-loop dictionary pipeline using Wiktionary and Wikidata evidence, Anthropic's API, structured outputs, cost controls and manual review.

- **FormCoach**: My MSc research project for on-device exercise coaching. I built the Flutter and Kotlin mobile pipeline around CameraX and MediaPipe, then created a Python workflow that turned 420 public videos from 25 subjects into 5,292 phase-normalised repetitions for model comparison and subject-wise evaluation.

- **Sage Studio**: A Flutter and Flame authoring tool and runtime for branching stories. I built SageScript, a Dart language with its own lexer, parser, typed AST, static analyser and deterministic runtime, plus a FastAPI/OpenCV service for preparing layered character artwork.

## Commercial product work

That work included Flutter delivery, AWS-backed receipt processing, live energy telemetry, payments and subscriptions, App Store and Google Play delivery, CI/CD, and a React/TypeScript marketing website.
